# Arsenal 0.4.5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Mac that is looked after (sturdier OS test, more file types), a sounds folder that exists on first run, and a version row as the pane's last line.

**Architecture:** Pure helpers in `arsenal/hooks/chime.ts` and `menu.ts` carry the decisions and are unit-tested; `register.tsx` does the reading, writing and drawing; `render.test.ts`'s fake world gains a Mac and a place to record writes. The version lives in a new `hooks/version.ts`, as ctx does, because a hooks module cannot read its own manifest.

**Tech Stack:** TypeScript hooks modules, `claude-code/testing` (`claude plugin test arsenal`), `$.fs` / `$.env` / `$.process`.

**Spec:** `arsenal/DESIGN.md`, section "0.4.5: a Mac that is looked after, a sounds folder that exists, a version row" (approved 2026-10-24).

## Global Constraints

- Version **0.4.5** (0.4.4 is skipped on purpose). `plugin.json` `version` equals `VERSION` in `hooks/version.ts`.
- The row reads `arsenal v0.4.5 · 2026-10-24`: dim (`dimColor`, `color="inactive"` as ctx), the **last** row, below the note line. `RELEASED` is ISO and is the day of the release, set when merging.
- Windows lists only `.wav` and `.mp3`. A Mac also lists `.m4a`, `.aiff`, `.caf`. Same name in several formats: `.wav`, `.mp3`, `.m4a`, `.aiff`, `.caf` in that order of preference.
- The OS is Windows when `OS` is `Windows_NT`; else a Mac when `/System/Library/Sounds` exists or the home starts with `/Users/`; else Linux.
- The sounds folder `<home>/.claude/arsenal/sounds` gets a `README.txt` **only when the folder is missing**; a failed write is silent.
- `hooks/` code changes go on branch `arsenal-0.4.5` with a PR (repo CLAUDE.md). Hooks that draw in the band: none here. Hook helpers must not be named like an engine hook call (`sound()` broke the module in 0.4.0).
- Verify with `claude plugin test arsenal` and `claude plugin validate . --strict` (what CI runs).

## Review Focus

- A Mac whose home is not under `/Users/` (an external volume) still plays: pinned in Task 2.
- A folder the person emptied, or made by hand, is never given a `README.txt`: pinned in Task 4.
- `README.txt` is not a choice in either sound list: pinned in Task 4.
- `song.aiff` (4-letter extension) keeps its full name `song`; a Windows PC ignores `song.aiff`: pinned in Task 3.
- A rejected `fs.write` at session start does not stop the session starting: pinned in Task 4.
